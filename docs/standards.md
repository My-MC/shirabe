## ラウドネス

計算方法は ITU-R BS.1770-5、表示と操作は EBU Tech 3341、LRA は EBU Tech 3342 に従います。

| 項目 | 資料の要件 | Shirabe |
|---|---|---|
| K 特性フィルター | BS.1770 表 1・表 2（48 kHz の係数） | 準拠。アナログ原型から各サンプルレートの係数を求め、48 kHz では表の係数と一致 |
| チャンネルの重み | L / R / C = 1.0、Ls / Rs = 1.41、LFE は除外 | 準拠 |
| ゲーティング | 400 ms ブロック、75 % 重なり、絶対 -70 LUFS、相対 -10 LU | 準拠 |
| M / S | 400 ms / 3 s の矩形窓、ゲートなし | 準拠。窓は 2.5 ms 以下の刻みで移動するため、Max M / Max S も正しく求まる |
| 更新頻度 | S は 10 Hz 以上、I は 1 Hz 以上 | 準拠（2.5 ms 以下ごとに更新） |
| I と LRA の操作 | 開始・一時停止・再開・リセットを I と LRA で同時に行う | 準拠（Pause / Continue / Reset） |
| Max M / Max S | 表示できること。I と同時にリセット | 準拠 |
| 目盛り | 「EBU +9」（-18〜+9 LU）を既定とし、「EBU +18」（-36〜+18 LU）も選べる | 準拠 |
| 単位 | 絶対値（LUFS）と相対値（LU）の両方を選べる。単位を常に表示 | 準拠。ARIB と ATSC のプリセットでは、各資料の表記に合わせて LKFS と表示 |
| 表示精度 | 小数点以下 1 桁まで | 準拠 |
| LRA の安定表示 | 測定開始から 60 秒間は、値がまだ安定していないことを示す | 準拠（`*` と注記を表示） |
| 最低限の表示 | Integrated、LRA、最大トゥルーピーク | 準拠 |
| 校正 | 1 kHz・-18 dBFS のステレオ正弦波で -18.0 LUFS | 準拠（画面で確認） |
| 適合性テスト | Tech 3341 表 1 のケース 1〜23、Tech 3342 表 1 のケース 1〜6 | すべて許容範囲内（[testing.md](testing.md)） |

EBU Mode の名称は、目標値プリセットに EBU R 128 を選んだときにだけ表示します。
Tech 3341 は EBU Mode の目標値を -23.0 LUFS（0 LU）と定めているためです。

## トゥルーピーク

| 項目 | 資料の要件 | Shirabe |
|---|---|---|
| 方式 | BS.1770 Annex 2：192 kHz 以上へ 4 倍オーバーサンプリング（96 kHz 入力は 2 倍） | 準拠。96 kHz 未満は 4 倍、192 kHz 未満は 2 倍 |
| フィルター | Annex 2 の 48 次 FIR は例示 | 独自のカイザー窓 sinc（1 位相 32 タップ） |
| 許容範囲 | Tech 3341 表 1 のケース 15〜23 で +0.2 / -0.4 dB | すべて範囲内（誤差は -0.17〜0 dB） |

## 目標値プリセット

| プリセット | 目標値 | 許容範囲 | 最大トゥルーピーク | 根拠 |
|---|---|---|---|---|
| ARIB TR-B32 | -24 LKFS | ±1 dB | -1 dBTP | TR-B32 §2.1.4、§2.1.5、§2.2.4 |
| EBU R 128 | -23 LUFS | ±1.0 LU（ライブなど目標値に合わせられない場合） | -1 dBTP | R 128 h)、m) |
| ATSC A/85 | -24 LKFS | ±2 dB | -2 dBTP 未満 | A/85 §6 |
| Spotify | -14 LUFS | 定めなし | -1 dBTP 未満 | Spotify for Artists |
| Apple Podcasts | -16 LKFS | ±1 dB | -1 dBFS（トゥルーピーク）以下 | Apple Podcasts for Creators「Audio requirements」（BS.1770-5 で測定） |
| Custom | 利用者が指定（-40〜-5 LUFS、初期値 -14） | 利用者が指定（0〜5 LU、0 は許容範囲なし） | 利用者が指定（-10〜0 dBTP、初期値 -1） | 資料に基づかない値。目標値を公表していないサービス向け |

各プリセットについて、次の点に注意してください。

- ARIB TR-B32 は、サンプルピークメーターで管理する場合の上限を -3 dBFS としています。
- EBU R 128 は、品質管理での測定誤差として ±0.2 LU を認めています。
- ATSC A/85 の 2026 年版は、長尺番組をダイアログゲート付きの BS.1770-1 で測定するよう定めています。Shirabe はダイアログゲートに対応していないため、このプリセットは短尺番組（全体のミックスを測定）の基準に相当します。
- Spotify は、-14 LUFS より大きいマスターでは、トゥルーピークを -2 dBTP 未満にすることを勧めています。
- Custom の初期値は、特定のサービスの値ではありません。
- 次のサービスは、ステレオ音源の正規化の目標値を公式に公表していないため、プリセットにしていません（2026-11-26 に各社の公式ヘルプと配信者向けページで確認）。
  - Apple Music：Sound Check で音量をそろえると説明しているだけで、数値はありません。
  - Amazon Music：アプリの「Loudness Normalization」設定の説明だけで、数値はありません。
  - YouTube：「Stable volume」や音量の自動調整の説明だけで、数値はありません。
  - Qobuz、TIDAL：正規化の目標値を説明したページが見つかりません。
- Apple Music の Dolby Atmos と 5.1 / 7.1 の納品基準（-18 LKFS 以下、-1 dBTP 以下）は公表されています。ただし 5.1 にレンダリングした音声で測る決まりのため、サラウンドに対応するまでプリセットにしません。
- Amazon が Alexa 向けの音声コンテンツに定めた基準（平均 -14 LUFS、トゥルーピーク -2 dBFS 以下）は、Amazon Music の正規化とは別のものなので、プリセットにしていません。

## VU メーター

VU メーターの要件は IEEE Std 152-1991 の第 2 章（Standard Volume Indicator）で確認しました。
同規格は、技術的な要件が 1953 年版と同じであると述べています。

| 項目 | 資料の要件 | Shirabe |
|---|---|---|
| 動特性（立ち上がり） | 基準の振れを与える正弦波を加えてから、300 ms ±10 % で基準の振れの 99 % に達する（IEEE 152 §2.3.4） | 準拠（2 次系で再現し、テストで確認） |
| 動特性（行き過ぎ） | 1 % 以上 1.5 % 以下（IEEE 152 §2.3.4） | 準拠 |
| 動特性（戻り） | 信号を止めてから、300 ms ±10 % で無信号の位置に戻る（IEEE 152 §2.3.4） | 準拠（テストで確認） |
| 整流 | 全波整流（IEEE 152 §2.2） | 準拠。4 倍（96 kHz 以上は 2 倍、192 kHz 以上はなし）にオーバーサンプリングした信号を整流します。原論文の整流特性（i = k·e^1.2）は再現していません |
| 周波数特性 | 1 kHz との差が 25 Hz〜16 kHz で 0.5 dB 以下、35 Hz〜10 kHz で 0.2 dB 以下（IEEE 152 §2.3.1） | 準拠（44.1 / 48 / 96 kHz でテスト） |
| 反転誤差 | 0.5 vu 以下（IEEE 152 §2.3.8） | 準拠（テストで確認） |
| 目盛り | -20〜+3 vu。図 9 の数字は -20、-10、-7、-5、-3、-2、-1、0、+1、+2、+3 と 0〜100 %（IEEE 152 §2.3.9、図 9） | 準拠 |
| 目盛りの位置 | 0 vu（100）は全目盛りの 2/3〜3/4 の間。0〜100 の目盛りは電圧に比例（IEEE 152 §2.3.9） | 準拠（+3 VU を全目盛りとした電圧比例で、0 VU は全目盛りの 70.8 %） |
| 基準 | アナログでは 0 VU = +4 dBu。デジタルでは 0 VU = -18 dBFS（EBU R 68）または -20 dBFS | 0 VU の基準を -24〜-8 dBFS で設定可能（初期値 -18 dBFS） |
| 表示形式 | 指針式のメーター | バーと指針を切り替え可能。指針は電圧に比例して振れ、+3 VU が全振れ、0 VU がその約 70.8 % です。規格図と同じ外観を再現するものではありません |

## PPM

IEEE Std 152-1991 の第 1 章（Peak-Program Meter）は、PPM の動特性を EBU Tech 3205 の通常モードと同じと定めています。
同規格で確認できた Type II の項目も、次の表に含めています。

| 項目 | 資料の要件 | Shirabe |
|---|---|---|
| Type I のバースト応答 | 10 ms で -1 dB、5 ms で -2 dB、3 ms で -4 dB（IEC 60268-10 を引用した二次資料） | 準拠（許容範囲は未確認のため ±0.5〜1 dB で試験） |
| Type I の降下 | DIN 45406 は 20 dB / 1.5 s、IEC は 20 dB / 1.7 ± 0.3 s | 20 dB / 1.5 s（両方の範囲内） |
| Type I の目盛り | -50〜+5 dB、目盛りは -50、-40、-30、-20、-10、-5、0、+5。0 dB = -9 dBFS | 目盛りの数値と基準は準拠。目盛りの位置は資料で確認できず、近似 |
| Type II のバースト応答 | EBU Tech 3205 表 2：100 ms で 0 dB ±0.5、10 ms で -2 dB ±0.5、5 ms で -4 dB ±0.75、1.5 ms で -9 dB ±1.0、0.5 ms で -17 dB ±2.0 | 準拠（テストで確認） |
| Type II の降下 | Tech 3205：24 dB を 2.8 ± 0.3 s | 準拠 |
| Type II の行き過ぎ | Tech 3205：0.5 dB 以下 | 準拠 |
| Type II の積分時間 | 10 ±2 ms（IEEE 152 §1.3.10） | 準拠（テストで確認） |
| Type II の遅れ時間 | TEST +9 dB の 1 kHz を加えてから +8 dB の表示まで 150 ms 未満（IEEE 152 §1.3.4） | 準拠（テストで確認） |
| Type II の過負荷特性 | TEST +9 dB・1.5 ms のバーストを 10 dB 上げると、表示は 5 dB 以上 10 dB 以下だけ上がる（IEEE 152 §1.3.11） | 準拠（テストで確認） |
| Type II のパルス応答 | 1 ms で TEST を示す単極パルスを短くすると表示が下がり、100 µs では TEST -10 dB 以下（IEEE 152 §1.3.13） | 準拠（テストで確認） |
| Type II の反転誤差 | 0.5 dB 以下（IEEE 152 §1.3.15） | 準拠（テストで確認） |
| EBU 目盛り（Type IIb） | Tech 3205 表 6：-12 / -8 / -4 / TEST / +4 / +8 / +12 が全目盛りの 10 / 22 / 35 / 51 / 67 / 80 / 93 %。+9 にも目盛り。TEST = -18 dBFS（EBU R 68） | 準拠（両端は 0 % と 100 % まで延長） |
| BBC 目盛り（Type IIa） | 1〜7。4 dB 間隔、1 と 2 の間だけ 6 dB。4 = アライメントレベル | 目盛りの値は準拠。資料は「ほぼ対数目盛り」とだけ述べているため、dB に比例して配置 |
| 周波数特性 | TEST の振幅で 25 Hz〜16 kHz の偏差が ±0.2 dB 未満（IEEE 152 §1.3.1）。Tech 3205 は 31.5 Hz〜16 kHz で ±0.3 dB | 準拠（44.1 / 48 / 96 kHz でテスト。オーバーサンプリングした信号を整流） |
| IEEE の目盛り | 最小 24 dB の範囲を dB に比例して 4 dB ごとに目盛る。TEST は範囲の中央。推奨の図 5 は -20〜+4 dB で、TEST は -8 の位置（IEEE 152 §1.3.16、図 5） | 準拠（「PPM IEEE」）。-20〜+4 dB を dB に比例して配置し、4 dB ごとに数字、2 dB ごとに目盛り。動特性は Type II と同じ。TEST（-8 の位置）は -18 dBFS（EBU R 68。IEEE 152 はアナログの 0.775 V rms のみを定めるため、デジタルの基準は EBU 目盛りに合わせました） |

## サンプルピーク
